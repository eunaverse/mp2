# Demo outline — target 2 minutes 40 seconds

Use the deployed website and keep the browser address bar visible. Check the actual API results before recording; choose categories with multiple recipes.

- **0:00–0:15:** Show the deployed URL and introduce Pantry, a React/TypeScript recipe app using TheMealDB, Axios and React Router.
- **0:15–0:45:** Switch to List. Type a recipe name without submitting to demonstrate filtering while typing. Clear it. Sort by recipe name ascending and descending, then by ingredient count ascending and descending.
- **0:45–1:10:** Switch to Gallery. Show recipe images. Select one category, add a second, then clear the filters. Point out the changing results.
- **1:10–1:45:** Open a gallery item. Show its specific URL, cuisine/category, ingredients, quantities and instructions. Use Next and Previous to change recipes.
- **1:45–2:05:** Return to the collection, switch to List, open another recipe. Refresh the detail URL to demonstrate direct-route loading.
- **2:05–2:25:** Show a no-results search and reset. Narrow the viewport briefly to show the mobile layout.
- **2:25–2:40:** Mention test coverage and close. Do not claim a grade or deployed CI result unless verified.
